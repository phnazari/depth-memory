Depth Memory

Residual connections pass information across depth by adding up layer outputs. We treat mixing over depth as storing and retrieving information across layers, and build a memory that solves a regression problem over depth.

Abstract

Residual connections propagate information over depth by additively accumulating layer outputs. Recently proposed alternatives, such as Manifold-Constrained HyperConnections (mHC) and Attention Residuals (AttnRes), instead use more expressive depth aggregation mechanisms that improve language modeling performance at scale. In this work, we consider the mixing of representations over depth a problem of storing and retrieving information across layers. Building on this perspective, we introduce Depth Memory (DM), a unified framework that describes the standard pre-layer-norm (PreLN) transformer, mHC, and AttnRes in terms of streams that carry information across layers. One such stream can be an explicit memory stream, which is queried to enrich the input to every layer, and whose output is subsequently written back into the memory for use by later layers. For AttnRes, this memory is a growing cache of explicit layer representations. For mHC, it is an implicit representation stored in an expanded residual stream. We then instantiate DM as a Linear Depth Memory (LDM), which propagates forward three streams: a standard residual stream, a memory stream, and an inverse covariance stream. We formulate the dynamics of the memory stream as a recursive least squares solution to a depth regression problem. We furthermore propose a hardware-aware implementation of LDM that reduces peak activation memory and memory traffic, enabling high-throughput training and inference. LDM consistently achieves the lowest perplexities among PreLN, mHC and AttnRes baselines at the 400M and 1.5B parameter scales, alongside competitive zero-shot accuracy, showcasing the practical utility of our framework.

One framework for depth mixing

Every method keeps some state that travels from layer to layer. Each layer reads from that state to form its input and writes its output back. Depth Memory describes PreLN, AttnRes and mHC this way, and the difference between them is what the state is and how big it gets.

One stream. Each layer reads the residual stream and adds its output to it.

Streams\((\mathbf x_l)\) Write\(\mathbf x_l=\mathbf x_{l-1}+\mathbf v_l\) Read\(\mathbf x_l\)

A growing cache of explicit layer representations. Each layer attends over the outputs of all earlier layers, so the state grows with depth.

Streams\(\big((\mathbf K_{\le l},\mathbf V_{\le l})\big)\) Write\(\operatorname{Append}(\mathbf k_l,\mathbf v_l)\) Read\(\operatorname{Attend}(\mathbf M_l,\mathbf q_l)\)

An implicit memory stored in an expanded residual stream: several copies of the stream, mixed between layers by learned matrices.

Streams\((\mathbf X_l)\) Write\(\begin{aligned}\mathbf X_l=\ &\mathbf X_{l-1}\mathbf H_l^{\mathrm{res}}(\mathbf X_{l-1})\\ &+\mathbf v_l\mathbf H_l^{\mathrm{post}}(\mathbf X_{l-1})^\top\end{aligned}\) Read\(\mathbf X_l\mathbf H_{l+1}^{\mathrm{pre}}(\mathbf X_l)\)

Three streams: the residual stream, a matrix memory of fixed size, and an inverse covariance. The memory holds the exact solution of a regression problem over depth, updated with recursive least squares.

Streams\((\mathbf x_l,\mathbf M_l,\mathbf P_l)\) Write\(\begin{aligned}\mathbf x_l&=\mathbf x_{l-1}+\mathbf v_l\\ \mathbf M_l&=\mathbf M_{l-1}+\mathbf u_l\boldsymbol\kappa_l^\top\end{aligned}\) Read\(\mathbf x_l+\mathbf M_l\mathbf q_l\)

Linear Depth Memory

A plain outer-product memory, \(\mathbf M_l=\mathbf M_{l-1}+\mathbf v_l\mathbf k_l^\top\), is linear attention over depth: it replaces the growing cache of AttnRes with a fixed-size summary. That update only approximates the solution of a regression problem over the layers seen so far, which we call depth regression:

\[\mathbf M_l^\ast=\arg\min_{\mathbf M}\ \sum_{i=0}^{l}\big\|\mathbf v_i-\mathbf M\mathbf k_i\big\|_2^2 .\]

Along the sequence, efficient training calls for parallel, approximate solvers. Across depth the layers already run one after another, so LDM keeps the exact solution with recursive least squares. With gain \(\boldsymbol\kappa_l\), prediction error \(\mathbf u_l\) and inverse key covariance \(\mathbf P_l\), each write is

\[\begin{aligned}\boldsymbol\kappa_l&=\frac{\mathbf P_{l-1}\bar{\mathbf k}_l}{\lambda_l+\bar{\mathbf k}_l^\top\mathbf P_{l-1}\bar{\mathbf k}_l},\\ \mathbf u_l&=\bar{\mathbf v}_l-\mathbf M_{l-1}\bar{\mathbf k}_l,\end{aligned}\]
\[\begin{aligned}\mathbf M_l&=\mathbf M_{l-1}+\mathbf u_l\boldsymbol\kappa_l^\top,\\ \mathbf P_l&=\big(\mathbf P_{l-1}-\boldsymbol\kappa_l\bar{\mathbf k}_l^\top\mathbf P_{l-1}\big)/\lambda_l ,\end{aligned}\]

with learned forgetting factors \(\lambda_l\) and importance weights inside \(\bar{\mathbf k}_l,\bar{\mathbf v}_l\). The memory is split into 16 groups, each with its own covariance. A hardware-aware implementation in CuTe DSL for Hopper and Blackwell GPUs updates the state in place during the forward pass and reconstructs earlier states in the backward pass, which keeps activation memory and memory traffic low.

Results at a glance

We pretrain Llama-like 400M models on 50B FineWeb-Edu tokens and Qwen-like 1.5B models on 100B, each method at its own tuned learning rate. LDM ends with the lowest loss at both scales. The paper has the full evaluations and throughput measurements.

How LDM is implemented

The memory belongs to one token and lives for one forward pass, so it adds nothing to the KV cache. Each write is paired with the read that follows it; the 1.5B model runs 57 of these edges. Two tricks keep it cheap: within a window of edges, \(\mathbf M\) is only updated in fast memory and written out once, and the backward pass rebuilds earlier states by subtracting saved rank-one updates instead of storing them.
